## 🚀 Projetos em destaque

### [AutoFlux](https://github.com/cesar90732-spec/autoflux-bot)
SaaS multi-empresa de automação de atendimento via WhatsApp. Conexão via QR Code (Baileys), atendimento automático com IA (OpenAI, Gemini, Claude), catálogo de produtos, agendamento de mensagens e cobrança recorrente via Pix.
🔗 Em produção: [autoflux-bot-1.onrender.com](https://autoflux-bot-1.onrender.com)
**Stack:** Node.js · Express · PostgreSQL · Redis · React · Vite · Tailwind · Docker

### Bot de Agendamento via WhatsApp
